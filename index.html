ACORDEÃO · AJUDA CONTEXTUAL
Como usar esta biblioteca?

Compare os estados, experimente os componentes e copie as estruturas. Os tokens compartilhados mantêm cores, tipografia e medidas consistentes em novas telas.

Quais estilos vêm do site original?

O azul #0052FC, as superfícies escuras, a fonte Satoshi e a linguagem dos cantos arredondados. A escala operacional, os estados e as cores funcionais são propostas para evoluir a identidade no sistema.

Os exemplos fazem operações reais?

Todos os valores são fictícios. As interações funcionam apenas nesta página, sem enviar dados ou executar compras.

07 / APLICAÇÃO

Consistência é o detalhe.

Regras simples para uma experiência reconhecível em qualquer tela.

01

Uma ação principal.

Reserve o azul para a ação mais importante de cada contexto. Use variantes secundárias para as demais escolhas.

02

Estados sempre claros.

Combine cor com texto ou ícone. Preserve o foco visível e explique como corrigir os erros nos campos.

03

Espaço para os dados.

Use a mesma escala de espaçamento. Alinhe números à direita e informe moeda, período e status.

Uma base pronta para evoluir.

Componentes em HTML, estilos compartilhados e interações em JavaScript.
